# 听读看 · 阅读与下载升级版

工具箱内的小说、音乐、视频入口。重启工具箱后，在「其他 → 听读看 · 资源小站」打开。

## 开始使用

- 小说：输入书名或作者，双击结果阅读。章节框可以输入关键词定位；可翻章、下载单章或全本／区间，最近使用记住章节和阅读位置。「全屏阅读」或小说页 F11 进入阅读窗口，Esc 返回；全屏也能翻章、打开阅读设置。
- 音乐：默认综合搜索酷我、网易、QQ、咪咕，歌手、专辑分别显示，常规版本排在 DJ／伴奏等版本前面。同名同歌手结果保留跨平台候选。输入歌名或“歌手 歌名”，双击收听；失效地址自动换源，也可点「换源」。
- 视频：搜索并双击作品。来源、线路和集数分开选择；「换源」保留当前集和进度。双击画面或 F11 全屏，Esc 返回；全屏仍可暂停、拖进度、调音量、换源和上下集。播完自动下一集。
- 视频清晰度：读取 HLS 主清单提供的分辨率／码率，默认优先高画质，失效时尝试较低画质。手动切换保留进度；下载使用当前选中的地址。源只提供一种画质时只有一个选项；未标明分辨率时在解码后显示实际尺寸，不生成不存在的 720p／1080p 地址。
- 已有媒体地址：顶部「打开链接」支持音频、视频及播放网页；动态网页可使用「网页播放」，检测到媒体后转入内置播放或下载。
- 默认使用自带兼容源，优先近期可用的候选，最多同时检索 8 个。普通界面只显示每个类别从 0 开始的固定源编号，不显示原始名称；同作品的来源合并，电视剧和动漫按类型／年份区分。

三个页面的搜索框、列表、下拉框、滚动条和菜单使用统一圆角与蓝色交互样式。正文、输入框、配置编辑框及网页播放器的右键菜单使用中文，保留复制／粘贴等快捷键。

下拉框和章节补全列表使用与字体匹配的固定行高，表头单独保留足够高度，避免高 DPI 下首行高亮、其他选项和表头文字重叠。

「阅读设置」支持字号 8–40 pt、行距 100–240%、字距 −1–12 px、阅读列宽 400–1600 px、页边距 8–96 px。背景可选纸白、暖纸、护眼绿、夜读，默认为暖纸。设置立即生效并保存，换章及重启继续使用；列宽受当前窗口可用空间限制。

「下载单章」保存当前文字章节。「下载全本」先显示章节范围，默认第 1 章至目录末章，起点和终点可以修改；同时预览章名与选中数量。按目录顺序合并成一个 UTF-8 TXT，保留每章标题。范围来自当前源已返回的目录。

入口、分类页、搜索框、操作按钮、右键菜单和高级维护均配有项目内生成的图标。44 个 SVG 保存在 `assets/media_hub/icons/`，合计约 12 KB，透明背景，支持缩放及深浅背景换色。以后可逐个替换 SVG，文字与功能独立保留。

## 自动处理异常

视频播放前检查 HLS 清单及第一片；地址失效则尝试同集的其他线路／来源。播放报错或连续 22 秒没有进度时也会换源，尝试过的地址本次不重复尝试。无法匹配同集时不会跳到其他集。

HLS 连接复用，并预读接下来两片；缓存上限 48 MB，单片上限 16 MB，切换播放任务时清空。缓存只在内存中，不建立后台常驻服务。网络速度和上游线路仍会影响流畅度。

音乐先验证媒体地址；播放时再核对实际时长与平台元数据，明显不符的地址继续换源。每次最多尝试 12 个地址，避免无限重试；校验无法识别所有错音情况。小说目录／正文读取失败会尝试当前作品的其他匹配来源。

## 导入和维护

日常使用不需要导入配置。进阶功能在「设置 → 高级维护…」，这里同时显示编号和原始名称，保留原始文件、网址、更新提示和最近错误，便于后续查找新版。可导入文件、粘贴配置或导入网址。文件支持阅读 JSON、LX JavaScript、Kazumi XPath、TVBox JSON，以及含媒体直链的文本。GitHub `blob` 文件链接会转换为原始文件链接。

网址需要指向实际的 JSON／JS 配置，而非普通介绍网页。「网址订阅」可以刷新配置、查看最近错误和移除旧网址；移除网址不会删除已导入源。本地文件更新后再次导入即可。

相同身份的源重复导入会更新配置，保持已有启用状态；完全相同的配置不重复添加。更换域名可能形成新条目，旧源可以停用或归档。编辑单个源会重置检测状态；基础书源字段去掉 JS 后会重新识别兼容性。

检测时可按 Ctrl 多选。维护检测检查书源／视频源的搜索请求及音源初始化；实际打开视频还会检查清单／分片。音乐解析每轮尝试最多 4 个音源，并保留同歌曲的跨平台地址作为候选。「初始化通过」不代表所有歌曲都能取得播放地址。

连续请求失败 3 次会自动停用。没有搜索结果不算失效。「清理失效」只归档连续失败条目，不删除配置；选中后「启用／恢复」可恢复。需要其他引擎的条目保留为未启用状态，避免被当成普通接口搜索。

音乐已取得链接但某一媒体地址失效时，记录为本次资源错误并尝试其他音源，不因此停用整个音源。可换歌曲或平台再试，避免一个平台的过期地址影响其他平台。

导入、停用和归档前自动创建数据库备份，保留最近 10 份。「恢复备份」会先备份当前状态，再恢复所选备份。还可以「导出备份」保存全部源及启用状态，或「导出原始」把单个配置送回原应用。两份 TVBox 完整组合配置也单独保留，包含直播、解析器、规则等全局字段。

## 当前兼容范围

初始包去重后含 525 个书源、18 个 LX 音源、116 个视频／参考条目，另保留 2 份完整 TVBox 配置。401 个条目启用了当前适配器；这是兼容候选数量，实际可用性以使用和检测结果为准。

| 格式 | 当前处理方式 | 遇到变化时 |
| --- | --- | --- |
| 阅读书源 | 基础 CSS／XPath／JSON、常见模板、请求头和 GET／POST；读取目录与正文 | 修改字段或重新导入；复杂 JS／登录流程保留配置，使用原应用 |
| LX 音源 | 事件、请求、Buffer、常用加密及压缩接口；网易／酷我／QQ／咪咕搜索，插件解析播放链接 | 检测音源、换源、重新导入新版脚本；各平台可用性分别以实际播放为准 |
| 视频采集接口 | MacCMS JSON／XML 搜索、详情、线路和选集 | 更换集数／线路／源；接口正常不代表每个播放地址仍有效 |
| Kazumi | XPath 搜索和选集；播放页提取媒体，必要时网页播放 | 更新规则；新版 API 规则暂未适配 |
| TVBox 插件 | 原始条目与完整配置保存、编辑、导出 | `csp_*`／JAR 插件需要 Android 引擎，当前不在桌面执行 |
| 媒体直链 | 音频／视频播放和下载，HLS 自动合并 | 链接过期后重新获取，Referer 请求头可随配置保存 |

已有网页资源遇到验证或登录时，可打开「原网页」查看情况。当前没有完整阅读 JS 环境、Android 插件虚拟机、DRM 播放或网盘扫码流程。

## 下载失败后

小说区间下载按章进行，每章完成后保存检查点。失败或取消保留 `.part`／`.part.json`；「最近使用」可重试，同一来源、同一范围、同一保存路径从已完成章节继续。完整结束后才发布 TXT；失败章节不会静默跳过。目录变化时提示重新选择范围，切换来源或范围则重新下载，避免正文混合。有声小说章节没有文字正文时提示不能保存为 TXT。

直链文件先写入 `.part`；再次下载到同一路径、同一有效地址时尝试 Range 续传。服务器不支持续传则重新下载。完成后才变成正式文件。

HLS 使用现有 FFmpeg 合并到 MP4；取消或失败后重试从头下载。「最近使用」可打开完成文件或重试失败下载。如果原地址已过期，先重新打开作品获取新链接，再下载。后台同时保留一个下载任务，关闭窗口会取消进行中的任务。

## 数据与依赖

数据保存在项目 `data/media_hub/`：`catalog.sqlite3`、`backups/` 和默认 `downloads/`。最后选择的下载目录会记住。「存储目录」可以直接打开这些文件。运行时不需要依赖最初的 `D:\下载` 文件位置；源已导入初始包。

打包版本把数据写入可执行文件同目录的 `data/media_hub/`，避免保存在解压临时目录。打包时需要包含 `assets/media_hub/` 和 `libs/media_hub/lx_runner.js` 数据文件；本次验收使用源码运行环境。

复用工具箱的 PySide6、requests 与 FFmpeg 核心。LX 宿主需要支持 `--permission` 的 Node.js 22.13+，本机验证版本为 24.11.1；脚本在独立进程运行，限制时间、内存和文件操作。小说解析新增的轻量依赖已安装到本机 Python 3.13，其他环境请用启动工具箱的同一 Python 执行：

```powershell
python -m pip install -r libs/media_hub/requirements.txt
```

FFmpeg 优先复用「大丸视频压缩」的现有核心，其次使用 PATH 中的 `ffmpeg`。Qt 媒体插件按需加载，并将自身 DLL 目录加入当前进程的搜索路径。未安装 QtWebEngine 时，网页播放交给系统浏览器。

## 验证与来源

2026-10-06 真实窗口验证：综合搜索把周杰伦《晴天》《稻香》、BEYOND《海阔天空》排在前列，音乐实际解码并推进进度；《牧神记》103 集及《凡人修仙传》动漫 194 集目录可读取，两部均完成全屏、退出全屏、跳至一分钟、继续播放约 20 秒及下一集测试。窗口捕获另确认全屏原生画面和控制条可见。小说读取 635 章目录，切到第二章后得到 2316 字正文。

这是所测章节与片段的结果，不代表整部作品每一集都可用。量子接口本次一些播放地址返回 404，已由运行时检查及换源处理。真实 HTTPS 片段下载、合并及解码和本地 HLS 下载回归检查均通过；18 份本地 LX 脚本初始化验证来自上一版。

本次升级另实测 QQ、咪咕的周杰伦《晴天》，实际解码时长分别约 269.8 秒和 269.8 秒；异常 9 秒提示音被时长校验跳过，咪咕可用候选已加入平台优先顺序。小说 635 章目录的前两章完成顺序下载与全屏阅读；《牧神记》识别到 1920×1080 并继续播放。选择较低清晰度后下载的本地测试视频解码尺寸与选择一致。
