# 听读看

baibox 内置的阅读与媒体工作台。入口位于「其他 → 听读看 · 资源小站」，支持小说、音乐和视频的搜索、使用与资源管理。

## 小说

输入书名或作者，双击结果打开。章节框支持输入关键词定位，可通过按钮切换章节，阅读进度自动保存。

- **全屏阅读**：点击「全屏阅读」或在小说页按 F11，Esc 返回。
- **阅读样式**：字号 8–40 pt、行距 100–240%、字距 −1–12 px，可调整列宽与页边距。
- **阅读背景**：纸白、暖纸、护眼绿、夜读；设置随章节切换与重启保留。
- **章节下载**：「下载单章」保存当前正文；「下载全本」默认选中整本目录，也可指定起始章和结束章。

小说按目录顺序合并为 UTF-8 TXT，并保留章节标题。下载中断后，可在同一来源、范围与保存路径继续；缺失章节会提示错误。有声章节没有文字正文时不能导出 TXT。

## 音乐

支持酷我、网易、QQ、咪咕的单平台与综合搜索。输入歌名、歌手，或组合关键词，双击结果收听；搜索结果展示歌手、专辑与平台信息。

播放地址由自定义音源获取，失败时自动尝试其他候选。可选择音质、暂停、拖动进度、调节音量或下载当前音频。音质范围与歌曲可用性取决于音源和上游服务。

## 视频

输入片名，双击结果播放。来源、线路与集数分别选择，切换来源时尽量保留当前集与播放进度。

- 双击画面或按 F11 全屏，Esc 返回；全屏保留播放控制与上下集操作。
- 清晰度根据当前源提供的 HLS 分辨率或码率显示；单画质源仅提供一个选项。
- 下载使用当前选择的清晰度，HLS 视频通过 FFmpeg 合并为 MP4。
- 播放地址失效或持续缓冲时，自动尝试同集的其他线路或来源。

已有媒体地址可通过顶部「打开链接」播放。需要动态网页播放器的地址可使用「网页播放」，检测到媒体后转入内置播放器。

## 资源管理

日常界面使用固定编号显示来源。原始名称、配置、订阅与最近错误集中在「设置 → 高级维护」。

| 格式 | 支持范围 |
| --- | --- |
| 阅读书源 | 基础 CSS／XPath／JSON 规则、常见模板及 GET／POST 请求 |
| LX 音源 | 自定义 JavaScript 音源初始化与播放地址获取 |
| MacCMS | JSON／XML 搜索、详情、播放线路与选集 |
| Kazumi | XPath 搜索、选集与播放页媒体提取 |
| 媒体直链 | 音频、视频与 HLS 播放和下载 |
| TVBox 配置 | 导入、保存、编辑与导出；Android CSP／JAR 插件不在桌面执行 |

支持导入文件、粘贴配置与网址订阅。重复导入更新已有配置，保留启用状态；导入、停用或归档前自动创建数据库备份。

检测失败的来源可以停用或归档，之后恢复。搜索无结果不计为失效；单个媒体地址过期也不会直接停用整个来源。

复杂阅读 JavaScript、登录验证、DRM 及需要 Android 插件引擎的资源不在当前适配范围内，可从「打开原网页」继续使用对应服务。

## 下载与数据

下载先保存为临时文件，完成后才生成正式文件。直链支持服务器允许的 Range 续传；小说按章保存检查点；HLS 合并任务中断后重新开始。「最近使用」可打开已完成文件或重试下载。

数据位于 `data/media_hub/`，包含源配置、使用记录、备份和默认下载目录。最后选择的下载位置会自动记住。关闭窗口会取消进行中的任务。

## 运行依赖

复用 baibox 的 PySide6 与 requests。规则解析依赖可单独安装：

```powershell
python -m pip install -r libs/media_hub/requirements.txt
```

自定义音乐源需要 Node.js 22.13 或更新版本；HLS 下载复用「大丸视频压缩」的 FFmpeg 核心，或使用 PATH 中的 FFmpeg。网页播放需要 QtWebEngine，缺少组件时交给系统浏览器。
